# Agent_Gemini

Лёгкий консольный чат‑агент на базе Google Gemini с поддержкой локальных инструментов.

## Что делает проект

- Запускает интерактивный чат в терминале.
- Отправляет сообщения в модель Gemini и выводит ответы.
- Позволяет модели вызывать локальные инструменты:
	- открытие ссылок в браузере;
	- запуск простых команд оболочки;
	- чтение/запись файлов.

## Структура проекта

- main.py — основной CLI‑агент на базе google-genai.
- tools.py — набор инструментов (open_url, run_command, read_file, write_file).
- pyproject.toml — зависимости и точка входа agent.

## Требования

- Python 3.12+
- Установленный uv (рекомендуется) или pip


## Установка (uv)

1) Установить uv:

```bash
curl -Ls https://astral.sh/uv/install.sh | sh
```

Проверка:

```bash
uv --version
```

2) Установить зависимости:

```bash
uv sync
```

Команда автоматически создаст виртуальное окружение и установит зависимости из pyproject.toml.


## Настройка API ключа

В текущей версии ключ API захардкожен в коде (main.py). Для безопасности рекомендуется заменить его на переменную окружения.

Минимальная настройка:

```bash
export GEMINI_API_KEY=<YOUR_API_KEY_HERE>
```
Можете брать Api клюя на сайте https://aistudio.google.com/


## Запуск

### Вариант 1: через модуль

```bash
uv run python main.py
```

### Вариант 2: через entrypoint

```bash
uv run agent
```

## Пример использования

После запуска вводите текстовые сообщения в консоль. Агент отвечает как обычный чат, а при необходимости вызывает локальные инструменты.
